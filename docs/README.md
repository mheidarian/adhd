# ADHD Assessment System - GitHub Pages

This directory contains the GitHub Pages landing page for the ADHD Assessment System project.

## Setting Up GitHub Pages

1. Go to your GitHub repository settings
2. Scroll down to the "GitHub Pages" section
3. Under "Source", select "main" branch and "/docs" folder
4. Click Save
5. Your site will be published at `https://[your-username].github.io/adhd_project/`

## Customizing Your Landing Page

To update your landing page:

1. Edit the `index.html` file in this directory
2. Update the link in the CTA button to point to your actual deployed application
3. Commit and push your changes to GitHub

## Note

This is just a static landing page. The actual Django application must be hosted on a platform that supports Python/Django applications.
